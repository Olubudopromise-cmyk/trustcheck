# TrustCheck User Flow

## Homepage

The user lands on the homepage.

They see:

- Logo
- Search bar
- "Verify anything"
- Recent searches
- Example searches

↓

The user enters:

- Website
- Email
- Phone number
- Domain
- IP
- Business

↓

TrustCheck detects the input type automatically.

↓

Verification begins.

↓

Results page shows:

- Exists?
- Trust Score
- Risk Level
- AI Explanation
- Evidence
- Sources
- Related checks

↓

User can:

- Save result
- Share result
- Download PDF
- Report scam

↓

The user explores the results details:

- Checks the trust score breakdown
- Reviews risk categories and severity
- Reads the AI explanation in plain language
- Examines evidence for each finding
- Opens source links for external verification
- Sees related checks and similar entities

↓

The user can take follow-up actions:

- Run another verification
- Compare current result with previous searches
- Add a note or bookmark the verification
- Save the item to a history list or dashboard
- Flag the result for later review
- Open advanced analysis for website, email, phone, or IP

↓

If the input is invalid or incomplete:

- Show guidance for supported types
- Prompt for a valid website, email, phone, domain, IP, or business name
- Offer examples and autofill suggestions
- Explain why verification could not complete

↓

Authenticated user flow:

- Sign in or sign up to save searches
- Access verification history
- View saved reports and favorites
- Manage API keys and account settings
- Submit community scam reports and review their status

↓

Reporting and feedback:

- Submit a scam report with context and evidence
- See confirmation that the report was received
- Get a follow-up status screen if investigation is available
- Provide feedback on the accuracy of the verification

↓

Ongoing trust experience:

- Return to the homepage for a new search
- Use the dashboard to monitor trusted and risky entities
- Receive alerts for previously saved items with new risk changes
- Share verified results with others via link or PDF

↓

Goal:

- Help the user answer “Can I trust this?” quickly
- Provide clear evidence, actionable risk guidance, and next steps
- Make verification repeatable, reliable, and easy to understand
