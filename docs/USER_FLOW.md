# TrustCheck User Flow

## Homepage

The user lands on the homepage.

They see:

- Logo
- Search bar
- "Verify anything"
- Recent searches
- Example searches

↓

The user enters:

- Website
- Email
- Phone number
- Domain
- IP
- Business

↓

TrustCheck detects the input type automatically.

↓

Verification begins.

↓

Results page shows:

- Exists?
- Trust Score
- Risk Level
- AI Explanation
- Evidence
- Sources
- Related checks

↓

User can:

- Save result
- Share result
- Download PDF
- Report scam
